# ELITE Spaces fix list (Oct 21, 2026)

These came from agents testing the live demo (https://elite-spaces-demo.onrender.com) and from the last
fix-and-check run. A second agent reproduced each one before it went on this list. None of them stops the demo.

## Medium

1. **Schedule shows later sessions as "Attended" during a check-in.** While a student is checked in, every
   later session that day reads "Attended" (with the morning check-in time) on Schedule and on Home's
   "This week". It corrects itself when they check out.
   Where: `src/modules/enrollment/service.js` (open-visit overlap rule); `src/modules/attendance/service.js` uses the same rule.
2. **iPhone home-screen icon doesn't show.** The app ships only an SVG icon, which iPhones ignore for
   Add to Home Screen, so families get a blank or screenshot icon instead of the ELITE logo. Needs PNG icons
   (180px apple-touch-icon, plus 192px and 512px for the manifest).
3. **Old account still showing after a sign-in in another tab.** When someone signs in as a different person in
   another tab, the first tab keeps the old name and menu. Anything saved there is saved under the new account,
   which matters on a shared front-desk computer.
4. **The demo clock is open to anyone.** Demo mode lets anyone with the link move the shared clock or run
   scheduled jobs. It's by design for the demo, but someone could move the clock in the middle of a test. Option: limit
   the dev controls to signed-in users.

## Low

5. **Student request status goes stale.** A student's request still says "Approved · enrolled" after the parent
   drops that session, and the student isn't told.
6. **Mid-session enrollments missing from "This week".** A session added while it's in progress shows "on now" on
   Home but is missing from "This week" until the student checks in.
7. **Needs-review button names.** For screen readers, the "Time is right" and "Fix time out" buttons have names
   that don't contain their visible text.
8. **No warning when moving a director.** "Make someone director" moves a location's only director away with no
   warning.
9. **No time zones on the HQ report.** The all-locations report lists Toronto and Irvine times side by side with
   no time zone label.
10. **Location order differs.** The announcement composer lists locations in a different order from the rest of
    the app.
11. **Missing security headers.** No HSTS or clickjacking protection, and the "X-Powered-By" header shows the
    server software.
12. **Back-to-back status runs behind.** During a back-to-back stay, the student's status still names the first
    session and its past end time for the 30 minutes after it ends.
13. **Stale screen after a refused scan.** After a refused scan, the check-in status card is out of date until the
    page is refreshed.
14. **Auto check-out notice.** The automatic check-out notification doesn't name the session; the scan and staff
    ones do.
15. **Blocked requests disappear.** A session request that was approved but blocked (for example by the weekly
    cap) drops off the parent's Schedule after 14 days.
16. **PDF hours box.** The hours box can show two figures 0.01 apart, because totals are sums of rounded
    visit hours.
17. **Small accessibility and layout issues:**
    - Two shell buttons have screen-reader names that don't start with their visible text (sign-out and More).
    - At very small phone widths (320px), the notes edit hint shifts the card.
    - Focus jumps to the top of the page after "Refresh numbers" in News.

## Already decided, not bugs
- A director can't end an emergency alert early, and there's no combined activity feed. These are ideas beyond
  the PRD (see `docs/open-items.md`), waiting on ELITE's call.

## Notes for fixing
- Any redeploy resets the demo's data (free plan, no disk). Redeploy only when nobody is mid-test.
- Fixes go through the same process as before: a test plus a deliberate-break check for each fix, and a fresh
  checker before anything ships.
